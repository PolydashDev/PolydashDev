## Polydash

Open-source DeFi infrastructure on Robinhood Chain (chain ID 4663).

- **Staking-as-a-Service:** permissionless, pre-funded reward pools for any ERC-20.
- **Polypad:** token launchpad with a commitment window, bonding curve and graduation to Uniswap V4.
- **On-chain AI agents:** Poly Agent (staking analytics) and PolyCTO (launch analysis and heuristic contract scans). Agents are non-custodial.

**Featured repository:** [PolydashDev/Polydash](https://github.com/PolydashDev/Polydash): contracts, ABIs, deployments, agents and docs.

**Stack:** Solidity, Foundry, OpenZeppelin, Uniswap V4 hooks, Next.js, TypeScript, Python.
